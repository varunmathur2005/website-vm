# Varun Mathur - Portfolio Website

Personal portfolio website built with Next.js, featuring a blog with MDX support.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- MDX for blog posts
- Vercel Analytics & Speed Insights

## Development

```bash
pnpm install
pnpm dev
```

Visit http://localhost:3000 to view the site.

## Features

- MDX and Markdown support for blog posts
- SEO optimized (sitemap, robots.txt, JSON-LD schema)
- RSS feed
- Dynamic OG images
- Syntax highlighting
- Dark mode support
- Responsive design
